## PC 游戏界面

每重的修为进度按比例提供 1 攻击、1 防御和 5 气血。修为受损时本重的进度加成随之回落，已完成境界的修炼加成计入该境界的基础。升一小重额外获得 3 攻击、2 防御和 20 气血，跨入大境界则额外获得 12 攻击、8 防御和 80 气血。角色面板、战斗力与秘境使用同一套生效属性。首次到达筑基可从中品武器、护甲、项链中领取一件。奖励保存在角色存档中，可留待稍后选择。
 
从筑基起，普通一重的总灵力消耗按自然回灵约 4 至 8 小时设定上限，九重晋阶上限为同段的 1.5 倍。装备、丹药与已有修为可缩短等待。

顶部常驻境界、战斗力、修为、灵力、灵石和强化石。侧栏可直接进入角色、装备、强化和灵宠。炼丹页分为炼制、丹方、药材；丹方标签列出已掌握丹方及未掌握丹方的残页进度。角色页的穿戴部位直接列出每件装备的属性和数值，点击部位换装，也可直接卸下。强化与洗练集中在侧栏的强化页。切换玩法只更新主区域，角色进度继续保存在原存档中。

## 玩家成长与回归

修炼页支持点击打坐一次，或按住鼠标左键、空格连续打坐。长按约四分之一秒后开始连续结算，随连续次数加速，最快约每秒 18 次；日志在结束时合并显示次数与消耗。每次沿用手动打坐的消耗和双倍修为概率；松开、离开页面或灵力不足时停止。手动按住期间暂停自动修炼结算，松开后按原设置继续。

- 领取新手礼包可获得 20,000 灵石。成就条件达成后自动结算，界面会合并提示本次获得的灵力。修炼页显示下一境界、灵力缺口及按当前回灵速率攒够一键突破所需灵力的预计时间。
- 游戏在浏览器本地存档中记录回灵时间。再次进入时，按境界和装备的常驻回灵速率补充灵力，最多计算 8 小时，并受当前灵力容量限制。离线期间累计灵力和已开启的秘境挂机收益；自动修炼在游戏运行期间每秒结算一次，优先保留设定的灵力，余额足够时直接突破一重，否则逐次打坐。缺少回灵时间的旧存档从首次打开后开始计时。
- 简单秘境首通第 1 层赠送聚灵丹方及一炉药材。炼丹页可选定未掌握丹方研习，探索残页优先补齐目标；全部掌握后残页掉落改为当地药材。探索页显示各地药材及后续地图的开放境界。重复服用同类药效延长时间，强度取较高值。
- 装备品质从低到高为凡品、下品、中品、上品、极品、仙品。装备列表、装备详情和抽奖结果都直接标注品质。
- 抽奖页可查看各卡池的实际单抽概率。综合池中装备与灵宠各占一半。有适用于当前卡池的心愿时，每抽消耗 200 灵石；普通抽取消耗 100 灵石。卡池结算和回灵均在浏览器内运行，无额外服务费用。

装备列表和抽奖结果会对比同部位装备的属性，保留的抽奖装备可在结果页直接穿戴。装备页逐项显示装备数值，括号内的增减表示与已穿戴装备的差值。点击装备名称可查看详情，点击部位可换装。旧存档里被取整为零的已知装备词条按原部位、品质、等级和强化等级补算。秘境页面的最近一场战报显示结算回合、剩余气血和实际奖惩。

装备最高可强化至 +100。强化页显示下一级成功率、材料费用以及每项属性的前后数值。强化页在角色正下方并排显示「一键强化」和「确认强化」，下方预览选中装备的成功率、消耗和属性变化。定向洗练消耗 5 洗练石，选择已有词条即可预览确定的增量，增量随品质、境界及装备强化等级增长。备用装备按穿戴时预估战力，概率类词条达到角色有效上限后停止投入。随机重洗每次消耗 10 洗练石。一键强化立即尝试每件可升级装备一次，优先已穿戴装备，按钮旁显示本次结果和消耗。首次强化必定成功，此后成功率每级下降 5 个百分点，最低为 25%。成功才消耗强化石，失败保留原材料和等级。

秘境通关任意一层后可选择该难度的已通关层挂机。每小时获得层数 × 难度倍率 × 120 灵石；所有已通关层均产洗练石，简单难度第 1、5、10、20 层每小时分别产 1、5、8、13 颗，其他难度乘以难度倍率。手动通关精英层和首领层分别获得难度倍率 × 2 和 × 5 颗。挂机在手动秘境挑战及选择增益期间暂停，离开秘境页后继续。每次离线最多结算 8 小时，与灵力容量独立。收益自动入账，累计收益和上次离线结算可在秘境页查看，进度随本机存档保存。

当前难度的未通关层可以从角色页或秘境直接重试。每个难度在本地存档中保留最近结算及同层上一次结果，换装或刷新后仍可比较两次的回合数和敌方剩余气血。重试获胜后停在战报，点击继续探索即可前往下一层。

PC 开局领取 20,000 灵石后可前往新手村，首次免费探索获得青竹剑。常规地点点按探索一次，按住鼠标或空格可连续探索，松开或灵力不足时停止。新手流程的侧栏依次提示探索、角色和秘境。玩家点亮起的武器位可穿戴青竹剑，再自行进入秘境试剑。简单前 3 层战败保留修为，第 1 层通关后停留在战报。已有游历进度的旧存档继续当前进度。

在线自动探索在切换页面后继续，灵力不足时等待恢复。探索和修炼同时开启时可以选择灵力分配优先级。新手游历进度和挂机设置随角色存档保存，探索日志保留本次游戏最近 80 条。成就页显示最近到账的奖励。

装备页的自动卖出按所选品质处理新抽装备，兑换强化石。灵宠页可直接放生换精华，或设置按品质自动放生多余的新抽灵宠，两页的设置与抽奖页同步。

装备品质旁显示该件装备的战斗评分。顶部战斗力按角色当前生效的战斗属性计算，包含已穿装备、出战灵宠及生效的战斗属性加成。装备列表可按同部位替换后的战力估分或修炼收益排序。战力估分折算攻防、气血、速度及战斗百分比属性，修炼收益比较回灵与修为获取倍率的乘积。灵宠列表提供推荐出战、可投喂、多余灵宠三种视图。抽到灵宠时领取该品质精华总额的一半（向下取整），剩余部分在放生时领取。批量和自动放生保留出战及已培养灵宠，同组保留主宠和一只升星材料；自动放生仅处理本次抽到的灵宠。升星消耗同品质灵宠，异名提供 1 点进度，同名提供 2 点。第 1 星需要 2 点，此后每星比前一星多需 2 点。作为材料的灵宠将已获升星进度转入主宠，并返还全部升级精华。每升一星使自身战斗属性提高 10%。在灵宠详情中可继承另一只灵宠的等级投入，双方的星级与进度分别保留，余下精华自动返入背包。秘境每层按出战灵宠启用先手、护体或追击特长，触发结果见战斗日志。培养数据随游戏存档保存在本机。

秘境选择增益时可指定一项在本轮刷新中保留。刷新消耗一次机会，其他位置换为不同的候选，点击增益本身才会选用并进入战斗。

## 本地开发与部署

安装 Bun 1.4.5 或更新版本。依赖使用提交的 `bun.lock`，开发、测试、CI 和 Docker 统一使用 Bun。

```bash
# 安装依赖
bun install --frozen-lockfile

# 开发环境运行
bun run dev

# 严格类型检查与回归测试
bun run check

# 构建生产版本
bun run build

# 本地预览
bun run preview
```

构建结果输出至 `dist/`，不纳入源码提交。提交到 `main` 后，GitHub Actions 会安装 Bun 依赖、运行类型检查和回归测试、构建站点，并自动部署到 GitHub Pages。Pull request 只运行检查和构建，不会发布站点。GitHub Pages 自定义域名留在仓库设置中；Pages 会在 Actions 部署时使用仓库中已配置的域名，无须在 `public/` 添加或生成 CNAME 文件。

从当前源码构建 Docker 镜像：

```bash
docker build -t vue-idle-xiuxian:1.1.0 .
docker run --rm -p 8183:8080 vue-idle-xiuxian:1.1.0
```

依赖升级至本次发布时的最新兼容稳定版本；TypeScript 使用和 Vue 类型检查器兼容的 6.0 系列。

## 存档与升级

升级前可在设置中导出存档。1.1.0 会把旧版 IndexedDB 存档一次性迁移至 Pinia 持久化状态，完成后移除旧数据，并保留独立 AES 存档的导入能力。读取旧档时会合并相同灵草、移除派生字段和过期丹药效果。新存档只保存玩家状态，灵草按数量堆叠。

灵力容量按当前境界修炼所需资源计算，至少容纳一整个境界的突破消耗；日月丹可提高容量。旧存档中已超过容量的灵力会保留。

项目于 2026 年 11 月发布 1.1.0，新增可配置的数据同步间隔，默认每 5 秒同步一次。间隔越短，同步越及时，但性能开销越高。具体变更见 [CHANGELOG.md](CHANGELOG.md)。
